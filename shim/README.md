# safeeasyapi has moved to stuntkey

This package was renamed. It only installs `stuntkey` and prints where to go.

```
pipx install stuntkey
```

Nothing is migrated from the old name: re-run `stuntkey get <service>` for each key and `stuntkey install` for your AI tools, and remove the old `safeeasyapi` hook and MCP entries from their settings.

Project: https://github.com/calasdan-sketch/stuntkey
