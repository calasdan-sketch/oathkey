# oathkey (npm)

Let your AI use your API keys without ever holding them.

```
npx oathkey start --simple
```

This package runs the Python program oathkey. It needs Python 3.10 or newer:
if it is missing, it says so - install it from https://www.python.org and run
again. Full guide: https://github.com/calasdan-sketch/oathkey
